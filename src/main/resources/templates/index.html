Chi tiết lỗi

1) So sánh UI theo URL (khuyến nghị cho kiểm thử hồi quy)

Ví dụ: http://localhost:8020 (nopCommerce v4.50)

Ví dụ: http://localhost:8021 (nopCommerce v4.60)

  • Hệ thống sẽ mở 2 URL bằng Chrome headless → chụp ảnh → so ảnh & vẽ khung đỏ vùng thay đổi → diff DOM.
  • Kết quả lưu ở thư mục run-results/<id>/ và truy cập qua /results/**.

2) So sánh UI theo Upload ảnh (nhanh khi đã có screenshot)

Chế độ upload chỉ so sánh ảnh (không có DOM diff).

Gợi ý sử dụng nhanh

  1. Đảm bảo 2 site chạy: V1 tại http://localhost:8020, V2 tại http://localhost:8021.
  2. Nhập hai URL rồi bấm So sánh theo URL.
  3. Xem ảnh V1/V2/Diff và bản diff DOM ở trang kết quả.
